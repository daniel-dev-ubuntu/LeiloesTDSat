# LeiloesTDSat - UC11 Atividade 3

## 🛠️ Implementações Técnicas Realizadas
* **Padronização de UI**: Todas as telas configuradas para [548, 491] com centralização automática via `setLocationRelativeTo(null)`.
* **Persistência de Dados**: Implementação de métodos no `ProdutosDAO` para venda e listagem filtrada de itens vendidos.
* **Estabilidade do Sistema**: Tratamento de exceções com `try-catch` em todas as operações de banco de dados.
* **Automação de Interface**: Chamada do método `listarProdutos()` no construtor da tela de vendas para atualização imediata dos dados.
